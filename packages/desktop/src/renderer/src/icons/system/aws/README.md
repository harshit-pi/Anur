# AWS icons

These are AWS's own service icons, from the AWS Architecture Icons package (release of 31 July 2026, the 32 px service icons, unchanged).

AWS publishes them for drawing architecture diagrams, which is what the system map does with them: <https://aws.amazon.com/architecture/icons/>.

The package itself carries no licence file, so AWS's terms on that page apply.

To add a service, copy its `Arch_<Service>_32.svg` here under a short name, then add it to `../index.tsx`.
